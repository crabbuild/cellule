## Embed the framework

Declare typed modules through `cellule-app`. Add `cellule-host` for a serving node. Add the optional peer adapter when using its signed transport. Your application still supplies the public API, authorization, provider credentials, async executor, and deployment policy.

Read [integration](/docs/guides/framework) for assembly, readiness, and drain, and [architecture](/docs/guides/architecture) for the complete ownership table.
