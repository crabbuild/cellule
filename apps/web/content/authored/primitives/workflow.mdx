## Use the typed capability

Obtain `workflow::<M>()` from an `ApplicationHandle` bound to the tenant and application. Its entry points are **start, signal, state**. The compiled module and Cell type determine the role and partition rules.

| Contract          | Behavior                                                                 |
| ----------------- | ------------------------------------------------------------------------ |
| Ownership         | One fenced writer per Cell.                                              |
| Mutation identity | Keep the same request ID when resolving or retrying one logical command. |
| Response          | Success follows durable publication or recoverable follower proof.       |
| Read consistency  | A receipt constrains a read in the same Cell.                            |
| Recovery          | State and recorded outcomes restore together.                            |

## Run the example

```sh
cargo run -p cellule-app --example workflow --locked
```

The [complete runnable source](https://github.com/crabbuild/cellule/blob/main/crates/cellule-app/examples/workflow.rs) includes module registration, provisioning, invocation, and shutdown. Examples use temporary SQLite and in-memory object storage.
